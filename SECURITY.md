# Security Policy

## Reporting a Vulnerability

We take the security and privacy of this tool seriously. If you discover any security vulnerabilities or privacy concerns, please report them directly to the repository maintainer instead of opening a public GitHub issue.

### How to Report

You can report vulnerabilities through the following channels:

1. **Contact Form:** Visit [angelpandey.com/contact](https://angelpandey.com/contact) and fill out the contact form.
2. **Direct Email:** Use the contact email address listed on [angelpandey.com](https://angelpandey.com) to reach out directly.

Please include a detailed description of the vulnerability, steps to reproduce it, and any potential impact. We will review your report as quickly as possible.

### Our Commitment

This application is built as a static, privacy-first tool that runs **100% locally in the user's web browser**. Because no scorecard data, JSON payloads, or personal details are ever sent to, processed by, or stored on an external server, the attack surface is significantly minimized. However, we remain committed to reviewing and addressing any valid concerns regarding client-side security or dependency vulnerabilities promptly.
